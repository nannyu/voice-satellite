# R1 Android Client

This directory will contain the Android 5.1-compatible Phicomm R1 satellite client.

Planned components:

```text
app
core/audio
core/wakeword
core/vad
core/session
core/diagnostics
media
hardware
protocol/api
protocol/homeassistant
protocol/custom
protocol/xiaozhi
```

Implementation starts only after Phase 0 hardware validation confirms the target unit's microphone/audio routes and stock-service conflicts.
